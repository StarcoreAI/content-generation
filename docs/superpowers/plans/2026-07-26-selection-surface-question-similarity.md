# 高频引用文章选择层表面报告：问题分组与相似度

## 范围

只改离线 CLI 报告、其纯聚合/相似度逻辑与既有抓取的编码兜底；不改爬虫、前端、路由或业务数据。

## 实施步骤

1. 为问题维度聚合和 3-gram Jaccard 分组统计补充失败测试，覆盖同 URL 跨问题、去重计数与组内/组间拆分。
2. 保持全局 Top N 抓取上限，将入选文章按其出现的具体问题展开；同一文章在各问题下保留该问题的引用次数与平台。
3. 让报告展示抓取状态、成功率、按问题分节的表面字段，以及 meta/title 的组内、组间均值/中位数和差值。
4. 既有静态抓取根据 HTTP 头和 HTML meta charset 探测编码，并保留失败原因；报告每个 URL 至少间隔一秒，不重试轰炸。
5. 跑定向与全量测试，检查只暂存本任务文件后独立提交。

## 验证

- 单元测试使用 mocked fetch，不进行真实外网抓取。
- 云端由用户先以 `--top 5` 人工核验编码，再以 `--top 30` 运行全量报告。
