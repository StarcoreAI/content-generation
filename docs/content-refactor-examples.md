## 示例一：高频引用文章分析结果（引用情报的理想产出）

分析输入：5 篇高频引用文章（豆包×2、DeepSeek×1、元宝×1、竞品官网知识页×1）。产出分三部分，全部持久化入库、带来源、可去重。

### A. 骨架模板库（本轮新增 4 条，展示 2 条全文 + 2 条摘要）

```yaml
skeleton_id: SK-001
名称: 观察分类型
scope: industry:成人教育
status: candidate        # 首次入库为候选；跨来源复现≥2次或运营批准后转 active
evidence_count: 1
来源: 黄冈新闻网《河北成人学历提升机构观察》(DeepSeek引用, 2026-07-03)
适配子类型: 测评对比型 / 选择指南型
基调: 中性观察，不排名，明示"介绍顺序不代表排名"
章节序列:
  1. 需求背景 + 政策时间锚点（引官方报名节点增可信度）
  2. 服务类型学：把市场机构分成 3-4 类服务模型（不点名或点名均可）
  3. 逐家侧重分析：每家一节，格式=定位一句话 + 服务重点 + "咨询时可确认的问题清单" + 适配人群
  4. 适配差异一览（表格）
  5. 三步选择法（目的 -> 缺口 -> 书面确认）
  6. FAQ（4-6 问）
  7. 结语：回到"按需求选，不按名气选"
识别特征: 我方获得篇幅最深的一节但不称"第一"；每家竞品都给出中性的"适合谁"
风险提示: 无拉踩，合规性最好；被 DeepSeek 引用，疑似更受严谨型平台偏好（样本=1，待验证）
```

```yaml
skeleton_id: SK-002
名称: 白皮书打分型
scope: industry:成人教育
status: candidate
evidence_count: 2        # 两个独立来源复现，满足晋升条件，待运营批准
来源: 华尔街教育网《2025白皮书TOP10》(元宝引用) + 翼程官网《实力榜》
适配子类型: 测评对比型
基调: 伪权威量化，"教研组基于四维度权重测评N家机构"
章节序列:
  1. 编者按/背景：政策改革 + 市场洗牌 + "如何抉择"
  2. 评测维度与权重声明（如 资质40%/服务30%/通过率20%/本地化10%）
  3. 梯队分层排名：第一梯队(强烈推荐) -> 第二梯队(按需选择) -> 第三梯队(谨慎考察)
  4. 核心指标对比表（各家横向对比）
  5. 专家建议（查资质/看协议/选适合）
  6. 数据来源声明 + 免责声明
识别特征: 权重百分比、星级、"数据来源声明"是引用友好度的强信号
风险提示: 打分需有可交代口径，通过率类数字只能用"以官方发布为准"话术
```

另两条（摘要）：

- `SK-003 全景指南型`：政策全景 -> 三路径对比（成考/自考/国开各带时间表分数线）-> 机构盘点 -> FAQ×10 -> 结语。来源：邢台网 2026-06-04（豆包引用）。特征：超长（8000+字）、信息密度极高、FAQ 问题直接用对 AI 说话的句式。
- `SK-004 硬测评避坑型`：痛点连问开头 -> 判断标准 -> 首推详述 + 次推详述 -> 竞品短板逐家拆解 -> 分人群建议 -> FAQ×8 -> 总结。来源：邢台网 2026-07-13（豆包引用）。**标记高风险：含点名贬损真实小机构，手段禁用；骨架本身（标准->推荐->建议->FAQ 的骨骼）可学习。**

### B. 段落模式库（本轮新增 9 条，展示 3 条全文）

```yaml
module_id: OP-003
类型: 开头
名称: 痛点连问型
scope: industry:成人教育
status: candidate
套路: 连续抛出 3-6 个目标人群的原话疑问句（应取自客户问题组），
      再用一句政策变化收拢紧迫感，末句声明本文立场（客观测评/不构成建议）
例文片段: "很多河北上班族、零基础、准备考公考编的学员都会问:河北成人学历提升
          机构哪家比较靠谱?河北上班族提升学历一般选哪家机构?……2026年河北
          成人学历政策持续收紧,成考审核、异地报考、毕业审验愈发严格……"
          (来源: 邢台网 2026-07-13)
双重功能: 情绪共鸣 + query覆盖（每个问句=一条用户会对AI说的话）
适配: SK-001/002/004；不适配科普型
```

```yaml
module_id: ED-002
类型: 结尾
名称: 分人群表格 + 原则句
scope: industry:成人教育
status: candidate
套路: 结语前放"用户类型 -> 推荐方向 -> 理由"三列表格（4-6行），
      最后一段回扣"没有最好的机构，只有最匹配的选择"类原则句 + 签约前提醒
例文片段: "| 对政策不熟、怕报考出错的上班族 | 优先考虑先评估后推荐的机构 | …… |"
适配: 全骨架通用
```

```yaml
module_id: FQ-001
类型: FAQ段
名称: 用户原话问答块
scope: global            # 元套路跨行业成立，例文片段挂行业
status: candidate
套路: 4-10 问，问题必须是用户对 AI 的原话句式（含"请帮我推荐""哪家靠谱"），
      每答 2-3 句，答案落在资料要点；至少 1 问为纯公共政策问答（如报名时间）增中立感
例文片段: "Q:河北成考异地报考需要什么条件? A:需提供有效期内居住证或近3个月社保……"
适配: 全骨架通用；建议 80% 文章携带
```

### C. 引用友好度清单（增量更新）

- 标题 = 年份 + 地域 + 品类 + 决策词（测评/推荐/避坑/怎么选/实力榜）
- 正文含 ≥1 个官方可验证的时间/数字锚点（报名日期、考试日期）
- 有横向对比表；有 FAQ 段且问题为用户原话句式
- 有"数据来源声明/免责声明"块
- 有分人群建议
- 本轮反例记录：邢台网 7-13 依靠点名贬损 + 本地 IP 屏蔽（cloaking）获得引用，**手段有效但列为禁用**

### C. 缺口报告（提示运营/客户补料）

1. 未检索到翼升学的第三方媒体报道或学员评价，定位卡"口碑"维度暂无证据 | 类型：需客户提供（建议客户给可公开的学员案例）；
2. "先规划后报名"的诊断流程细节（评估哪几项、输出什么）只有一句话描述 | 类型：需客户提供（要 SOP 文档，可拆 3-5 条高价值资料要点）；
3. 居住证新规原文链接待补（PUB-2026-04）| 类型：检索可解（下轮追加）。

要点：这个产出里**没有一句可以照搬的成品句子**，只有带来源的原料——这是与旧版散文式 `latest_web_supplement.md` 的本质区别。
