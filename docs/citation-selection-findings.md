# AI 引用选择规律总结（选择层实证，v1）

> 更新：2026-07-26。数据来源：崔红蕾（上海医美）、古齐装饰（昆山装修）、扬州苏韵（汽车音响改装）三客户 2026-07-24 前后的豆包爬取记录，配合"选择层表面报告"（高频 Top30 按问题分组 + 最低频档随机 30 篇对照）对被引文章的标题 / meta description / H1 / 首段做的横向分析。样本规模有限（三客户、单平台为主、单日切片），结论按可信度分级标注。三层模型已在介绍型（医美）和对比型（装修、汽配）两类行业交叉验证成立。

## 一、核心模型：引用选择是三层结构

### 1. 入池层——决定一篇文章有没有资格被检索到（可信度：高）

- **引用池极小**：10 个同意图问题的高频引用池总共约 30 篇文章。在这个量级下，单实体放 3-4 篇即可形成"每个问题都在场"的垄断。
- 入池靠：**站点权重**（39 健康网、有来医生、搜狐、婉宝网、列举网等有人经营的投放渠道；行业强相关）+ **标题主意图词**（城市 + 项目 + 实体名 + 决策词）。
- 持续被引的几乎全是投放文。低频池（被引仅 1 次档）约一半是医院官网 / 挂号平台目录页 / 空壳页，属检索噪声，不是竞争对手。

### 2. 问题分配层——决定入池文章落在哪些问题下、引得多稳（可信度：高）

- **同一意图簇的问题共享核心池**：10 个"上海+面部提升+医生"的不同问法，检索层基本当同一个查询处理，症状细节大部分被丢弃。
- **症状词逐字匹配产生梯度**：问题里的症状词能在文章标题/meta 里逐字找到的，引用频次满档；只沾边的衰减；完全没覆盖的直接消失。实证：崔红蕾品牌文 meta 含"法令纹加深、下颌线模糊"，在对应问题下排第 1、当天 3/3 轮被引；"线雕换方案 / 不对称 / 疲惫换脸感"三类词零覆盖，对应问题下 0 引用。
- 泛化词（如"审美在线"）不起作用，起作用的是具体症状词（下颌线、法令纹、初老、颧骨、恢复期）。
- 长尾文章靠症状词单点命中也能被捞（磨骨文靠"颧骨"一词在颧骨问题下被引 1 次），但主词不对进不了核心池。

### 3. 实体冗余层——决定被引稳定性（可信度：中，强怀疑待压实）

- 高频医生全部是**同名多篇跨站在场**（每人 2-4 篇、2-4 个站）；表面公式满分的孤文（赵寅局、李湘源案例）只有随机长尾级出场率。
- 崔红蕾"1 篇强文 + 1 篇弱文"的实体厚度介于两者之间，提及率也介于中间并在波动下滑，与该模型吻合。
- 替代解释未排除：发布时间新旧、单日切片偏差。验证方法：统计"实体名池内文章数（含低频） vs 该实体总被引次数"散点。

## 二、赢家文章的表面公式（可信度：高，但为必要不充分条件）

强势文章的标题/meta 重复以下模式，近乎公式：

1. **满身数字**：年限（15 年深耕）、百分比（92% 满意度、6% 低淤青率）、人数（3000+ 爱美者）、维持时长（5-8 年）。与 GEO 论文"加统计数据显著提升引用"一致。
2. **专属技术名**：每个实体一个独占命名（CFS 阶梯式折叠、7Dvline、微孔定位、双韧焕颜），制造只有自己能命中的检索词。通用术语（如"SMAS 筋膜层技术"）无独占性。
3. **标题模仿问句**：标题即用户会问 AI 的原句（"XX 怎么样？""口碑咋样？"），实体链完整（城市+实体名+项目+决策词）。
4. **meta 直接消解恐惧**：问题带恐惧（怕假面、怕创伤、怕恢复久），meta 给答案（自然不假面、切口隐形、恢复期短、不踩坑）。
5. **首段即摘要**：约一半 meta 是首段开头的截取（CMS 自动生成），首段写成什么样摘要就是什么样。

注意：公式满分 ≠ 高频被引（见实体冗余层）；公式是入场券。

## 三、其他确认的事实

- **能抓到的赢家 meta 覆盖率接近 100%**（崔红蕾 22/22，古齐 19/21）；"没 meta 也被引"的早期印象是抓取失败造成的统计假象。
- **模板化在选择层不受惩罚**：古齐侧土巴兔系同一 meta 模板换槽位批量铺文，全部被引。医美侧则是一医生一稿。两种打法共存，选择层既不奖励也不惩罚模板。
- **"被引 → 被提及"基本成立**（人工核对崔红蕾 3 轮：前两轮完全对应，第三轮出现 3 例被引未提及）。例外待查是容量性（回答点名医生数 < 引用文章数，结构性落选）还是轮次/账号级波动。
- **行业差异大**：医美泛推荐问题的高频文以单医生深度介绍型为主；装修、汽车音响等本地服务行业以"年份+城市+品类+决策词"对比榜单型为主（苏韵侧 64% 标题含年份，医美侧仅 3%）。"什么样的文章容易被引"没有跨行业的统一答案，但三层模型本身跨行业成立。
- **一稿多站复制不被去重，可在同一回答内重复占位**（扬州苏韵侧实证）：同一篇测评文一字不差挂在两个域名（baiyewang.net / byxx.com），两个 URL 各自被 6 个问题引用，且在同一问题的引用列表里同时出现；cnblogs 两个账号发近似同文同样各自被引。检索层按 URL 计位、不按内容去重——"一稿多站"直接翻倍占位。
- **"症状词"在对比型行业的等价物是车型/品类词**：新能源问法拉出极氪 001、蔚来 ET5ES6、理想 L7L8L9、特斯拉专属文；泛问法共享泛横评池。问题分配层的词匹配机制跨行业同构。
- **免费/低门槛渠道也在生效**：cnblogs 企业博客、地方论坛（羌溪花园）、分类信息站（列表网/百业网）的投放文都进了高频池，站点门槛远低于医美侧。

## 四、对内容生产的落地规则

1. **症状/场景词的写作提示（当前过渡工具）**：现有问题组中的 Query 不是销售侧真实问法资产，只能用于选择层观察。每个问题组优先取组内高引用的至少 3 篇不同文章，让模型同时看 Query、文章标题、meta 与首段前 300 字，提取可供运营落笔的具体场景词；运营页只展示“问题组 / Query / 场景词”。不展示命中格、不判断我方覆盖、不从这里自动选题。（崔红蕾已观察到的有效词包括法令纹、下颌线；线雕换方案、面部不对称、疲惫感/怕换脸是待复测方向。）
2. **成组投放而非孤篇**：同一实体名 2-3 个站、多篇成组，每篇埋不同的症状词组合；孤篇即使质量高也站不稳。对比型行业可加"一稿多站复制"（检索层不去重，重复占位有效）。
3. **标题写法**：城市 + 项目主词 + 实体名 + 决策词（怎么样/推荐/靠谱吗/口碑），标题即预判问句。
4. **meta/首段写法**：首段按"就是摘要"来写；塞可提取的数字（年限/比例/人数）；带专属技术名；直接回应目标问法里的恐惧词。
5. **给客户造专属技术名**并全组文章统一使用，形成独占检索词。

## 四点五、初步观察（待复测，暂不作为结论）

- **强场景词可直接"换池"（n=1，成人教育/翼升学，2026-07-26 人工测试）**：保持主词不变（河北+学历提升+机构+正规），仅把场景词换成"评职称卡学历"，结果三篇高引横评文全部消失，引用池整体变为成考指南/政策类内容，品牌提及来源转为各机构官网。推断：平台的检索词改写层是真正的分流闸门——弱场景词（省心/加班）只影响池内分配，自带领域的强场景词（评职称）会改写进检索词、直接切换整个内容池。
- 推论一（机会）：评职称/宝妈/退伍等强场景词问法是投放空白池，先按行业公式覆盖者独占。
- 推论二（官网兜底）：投放文未覆盖的问法上，模型转向机构官网取实体信息——客户官网的可抓取性与基础信息完整度有真实提及回报。
- **推论三（战略级痛点）：我们没有"真实用户怎么问 AI"的数据**。问法决定开哪个池，而我们监测的问题组是自己编的——如果真实用户的问法分布和我们编的不一致，我们的观测、覆盖矩阵、选题全部瞄准的是错误的池子。"问法资产"（真实/高保真的用户问法）仍是比素材更稀缺的上游资源，可能来自客户销售/客服咨询话术、平台联想词、行业社区原生提问和小规模换池实验。**产品边界：问法资产由销售侧收集和维护，本系统当前不建设问题库/问法库，也不把它纳入知识库施工。现有问题组只继续承担爬取与观察；可基于它做只读的“Query + 高引用文章表面 → 场景词”运营提示，但这不是销售问法库或真实问法覆盖矩阵。**
- 复测清单：同问题再问 2 轮（新会话）；"宝妈带娃""退伍"问法验证换池是否复现；"预算/性价比"弱场景词问法验证是否出现"池不换、定向文衰减"的半衰减形态。

## 五、未验证 / 待办

- 实体冗余散点验证（池内文章数 vs 总被引次数）。
- 发布时间对入池速度的影响（当前表面报告不含发布日期）。
- 回答侧吸收分析：被引未提及的轮次里引了谁、赢家表面长什么样；"数字多→更容易被写进回答"仍是推断。
- 搜索引擎对照组实验（搜到但未被引 vs 搜到且被引），验证选择权重的唯一严格方法。
- 工程：云端 playwright 系统依赖（libatk）+ Sync API 用于 asyncio 循环的 bug 未修，列举网/抖音/头条仍是抓取盲区；论坛类页面（羌溪花园）首段提取选择器抓到侧边栏推荐位，需修正。
- 古齐装饰按问题分组报告未出，"模板铺文→引用分布散"仍是推断。
- 苏韵侧每篇文章在每个问题下均只被引 1 次（无满引档），是当天只爬一轮还是池子轮换快，需对照爬取轮数确认。
