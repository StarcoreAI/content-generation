# 知识库当前边界

更新时间：2026-08-02

## 模块

- **客户资料库**：每客户独立的客户事实资料；运营显式选择时可供内容生产使用。客户移除章节保留原有的抑制语义。
- **竞品资料库**：每客户独立，以真实竞品名称 `##` 分节。名称可改，旧名来源映射到新名称；删除只删除当前章节，原始来源仍保留，后续同步可恢复。
- **Query 场景词库**：由问题组 Query 与高引用文章表面提取，作为轻量写作提示，不是销售问法库或覆盖矩阵。
- **行业写法库**：按行业、介绍型/对比型沉淀抽象写作路线；创建和删除直接入库。
- **质量门禁**：仅通用和行业两级，影响范围必须清楚，但不支持下载。
- **系统提示词**：只读的经审核模板目录，使用可选择纯文本展示；不允许编辑或下载。

## 编辑与导出

客户、竞品、场景词与质量门禁统一自动保存：输入 800ms 防抖、失焦立即保存、增删改名立即保存；失败提供重试。行业写法库本来就是操作即入库。

客户资料、竞品资料、场景词、行业写法库可分别导出 DOCX，只导出运营可见的已保存内容，不导出内部别名、抑制状态、原始抓取资料或密钥。质量门禁与系统提示词不下载。

## 记录库关系

选择层临时报告展示已删除。记录库只保留按问题组/Query 的场景词提示；它不改变知识库内容，也不自动改写内容生产。

## 硬边界

客户资料、竞品资料、内容上传资料不可混用。所有客户级读取、编辑、导出都必须执行客户访问控制；知识库不自动注入内容生产，运营必须显式选择。
